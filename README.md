# IssuesApp (vue-intermedio-issues)

## Instalar dependencias

```bash
npm install
```

Créditos:

Curso de Vue Intermedio de Fernando Herrera https://knowmadmood.udemy.com/course/vue-intermedio/learn/lecture/34777204

## Configurar ENV

Copiar `.env.template` y renombrar por `.env`

### Arrancar la aplicación

```bash
npx quasar dev
quasar dev
```

### Uso de Lint

```bash
npm run lint
```

### Formateo de archivos

```bash
npm run format
```

### Build para producción

```bash
quasar build
```
